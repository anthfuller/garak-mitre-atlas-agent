# Examples

config.example.json contains generic placeholders. Copy it outside the source folder before editing.

synthetic_fixture.jsonl is generated parser-test data, not a scan of any real model. It intentionally includes a detector-flagged quotation; the analyst disposition remains unreviewed. It is not a vulnerability demonstration.

headroom-worked-example.json is a sanitized actual paired-comparison excerpt, not synthetic data. It retains reported status/token fields but excludes private identities, paths and transcripts. Read [the worked example](../docs/worked-example.md) before interpreting its detector flag.
